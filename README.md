# 混沌实验室 · Chaos Lab

一组单文件、零依赖的交互式浏览器演示：混沌系统、分形、GPU 粒子模拟与交互实验。
每个 `.html` 文件都是完整的应用，用浏览器直接打开即可运行，无需构建、无需安装。

## 在线演示

**https://affine-13.github.io/chaos-lab/**

## 本地运行

```bash
# 任选其一
start Lorenz吸引子.html          # Windows
open  Lorenz吸引子.html          # macOS
```

或直接双击任意 `.html` 文件。

## 技术说明

- 所有演示为**单文件 HTML**，内联 CSS/JS，无任何外部依赖或网络请求
- 图形部分使用 Canvas 2D、WebGL 或 WebGPU，全部在客户端计算
- 中文界面
